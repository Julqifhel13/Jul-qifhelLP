# Landing Page Portfolio — React + shadcn Build Brief (For Gemini)

## Goal

Build a **high-end editorial landing page portfolio** using:

* React (Vite or Next.js)
* Tailwind CSS
* shadcn/ui components
* JavaScript (or Framer Motion for animations)

The output should feel **premium, minimal, and custom-built**, not template-based.

---

## Core Concept

Follow the **“Digital Curator”** approach:

* The layout should feel like a **gallery**
* UI must stay subtle — content is the focus
* Use **asymmetry + whitespace**
* Avoid rigid or overly structured layouts

---

## Design System Rules

### Colors

* Background: `#f9f9f9`
* Section contrast: `#f2f4f4`
* Cards: `#ffffff`
* Text: `#2d3435`
* Accent: `#5f5e5e`

### Strict Rules

* ❌ No borders
* ❌ No heavy shadows
* ✅ Use background layering for depth

---

## Typography

* Font:

  * Headline: **Manrope**
  * Body: **Inter**

### Scale

* Hero: very large (dominant)
* Section titles: medium
* Body: readable, well-spaced

---

## Layout Strategy

* Use **large vertical spacing**
* Avoid centered layouts everywhere
* Mix:

  * left-aligned content
  * offset sections
* Keep everything breathable

---

## Sections to Build

### 1. Navbar

* Sticky top
* Glass effect (blur + transparent background)
* Minimal:

  * Logo / Name
  * CTA button

---

### 2. Hero Section

* Strong headline (main focus)
* Supporting paragraph
* Clean layout
* No clutter

---

### 3. Portfolio Section

Display landing page projects using **cards**

Each card must include:

* Screenshot (from assets)
* Project title
* Tags (Funnel, Automation, GHL, etc.)
* CTA (View Project)

### Card Style

* No borders
* No heavy shadow
* Use soft background contrast
* Slight hover lift

---

### 4. Footer

* Minimal
* Low emphasis
* Clean spacing

---

## Components (shadcn-inspired)

Use or mimic:

* Button (rounded, pill style)
* Card (soft container, no borders)
* Badge (for tags)

### Button Behavior

* Slight scale on hover
* Smooth transition

---

## Animation Guidelines

Use:

* **Framer Motion** (preferred) OR vanilla JS

Animations:

* Fade-in on scroll
* Slight upward motion
* Smooth easing

Optional:

* Card hover lift
* Subtle image zoom

---

## Assets Handling

* Use provided screenshots
* Place inside cards
* Maintain spacing (no edge crowding)

---

## Code Structure

* Component-based architecture:

  * Navbar
  * Hero
  * PortfolioGrid
  * Card
  * Footer

* Clean and reusable components

---

## What to Avoid

* Generic templates
* Over-designed UI
* Too many effects
* Borders and dividers
* Crowded sections

---

## Expected Output

A **React + shadcn portfolio landing page** that:

* Feels like a **premium editorial product**
* Highlights my:

  * Landing pages
  * Funnels
  * Automation systems
* Uses clean modern UI principles
* Ready to run locally

---

## Final Instruction

Focus on:

* Simplicity
* Elegance
* Spacing
* Typography

The result should feel like a **high-end designer portfolio**, not a standard SaaS page.
